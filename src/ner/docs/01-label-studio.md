# Label Studio 地址标注配置

## 模板文件

`label/template/address_template.xml`

## 标注标签

所有标签统一在 `<Labels name="standard">` 下：

| 分类 | 标签 | 快捷键 |
|------|------|--------|
| 行政区划 | 省份、城市、区县 | 区县(1) |
| 街道/镇/乡 | 街道、镇、乡 | 街道(2) |
| 道路与路口 | 路、巷 | 路(3) |
| 高速公路/快速路 | 高速公路、快速路 | |
| 门牌/弄/号 | 弄、支弄、路号 | 弄(4)、路号(5) |
| 小区/村/子区域/宅 | 小区、村、子区域、宅 | 小区(c)、子区域(s) |
| 楼栋/单元/楼层/室 | 楼栋、单元、楼层、室号 | 楼栋(6)、室号(7) |
| 农村/集体地址 | 队、组、宅 | |
| POI/方向/其他 | 兴趣点、方向、其他、位置类型 | 兴趣点(p)、位置类型(q) |

## 数据导入

支持 CSV 或 JSON 格式，数据中需包含 `address` 字段：

```json
{"address": "北京市朝阳区建国路88号1号楼2单元301室"}
{"address": "上海市浦东新区张江镇科苑路150弄3支弄6号楼3层302室"}
```

## 标注示例

### 示例1
```
地址: "北京市朝阳区建国路88号1号楼2单元301室"

标注:
- 北京 → 省份 + 城市
- 朝阳 → 区县
- 建国路 → 路
- 88号 → 路号
- 1号楼 → 楼栋
- 2单元 → 单元
- 301室 → 室号
```

### 示例2
```
地址: "上海市浦东新区张江镇科苑路150弄3支弄6号楼3层302室"

标注:
- 上海 → 省份 + 城市
- 浦东 → 区县
- 张江镇 → 镇
- 科苑路 → 路
- 150弄 → 弄
- 3支弄 → 支弄
- 6号楼 → 楼栋
- 3层 → 楼层
- 302室 → 室号
```

### 示例3（交叉口 + 方向 + POI）
```
地址: "中春路与顾戴路交叉口南侧的闵行区体育公园"

标注:
- 中春路 → 路
- 顾戴路 → 路
- 交叉口 → 位置类型
- 南侧 → 方向
- 闵行区体育公园 → 兴趣点
```

## 标注建议

1. **省份和城市**通常重合，如「北京市」「上海市」，可同时标两个标签
2. **路名**只标含「路」「大道」等后缀的道路名，不带后缀的不标
3. **楼栋**包含「号楼」「栋」「幢」「座」等后缀
4. **单元**包含「单元」「门」等后缀
5. **交叉口**由「路」+「路」+「位置类型」组合，不标成一个整体
6. 一个地址片段可同时标多个标签，如「北京」标省份+城市
7. 无法归类的内容标为「其他」，地标/场所标为「兴趣点」

## 模拟标注数据工具（mock）

`label/mock/mock.html` 为静态页面，数据源与规则库从 `label/raw/` 读取（道路.txt、小区.txt、村.txt、兴趣点.txt、address_rules.json），按步骤组合字段，批量生成 Label Studio 格式的模拟标注 JSON。规则与数据源的修改会**直接写回 `label/raw/` 文件**，必须通过 `serve.py` 服务访问（不能直接双击打开）。

运行（在项目根目录）：

```bash
uv run uv run python -m tools.serve(已移除,仅供参考)
```

浏览器访问 `http://localhost:8000/label/mock/mock.html`。

`serve.py` 提供静态文件服务，并暴露保存接口：
- `POST /api/save_rules` → 写入 `label/raw/address_rules.json`
- `POST /api/save_source?key=roads|communities|villages|pois` → 写入对应 `label/raw/*.txt`

### 规则库

`label/raw/address_rules.json` 由 `label/exported/` 手动标注数据统计生成（地址字段序列模式 + 样本条数），并结合上海城市/农村地址特点补充内置规则，共 40 条，按**城市地址（25 条）/ 农村地址（15 条）**两类展示，如 `村+组+室号`(156)、`路+弄+楼栋+室号`(97)、`路+弄+小区+楼栋+室号`(51)、`路+弄+支弄+号`(60)、`小区+楼栋+单元+楼层+室号`(80) 等。

### 地址特点（规则依据）

**上海城市地址**
- 核心格式 `XX路XX弄XX号`，「弄」为上海特有（数字弄，与门牌同序数），弄内可再分**支弄**（`XX弄X支弄XX号`）；
- 里弄/小区命名：XX弄、XX里、XX坊、XX村、XX新村、XX花园、XX公寓、XX苑；
- 楼栋：X号楼/栋/幢/座；单元：X单元/X门；楼层+室号（如 3 楼 5 户 = 305）；
- 交叉口：两条路 + 位置类型（交叉口/路口）。

**农村地址**
- 标准格式：镇 + 村 + 组（队）+ 门牌号，如 `新明村三组15号`；
- 自然村/宅：XX村XX宅；平房直接 `XX村XX号`。

- **规则 = 地址前缀 + 地址构造步骤**：每条规则自带 `prefix`，一键生成时使用各规则自己的前缀；
- 点击「+ 新建规则 / 编辑 / 应用」都会**弹出对话框**，对话框内即「地址构造步骤」（字段序列、前缀、生成条数），在对话框中配置后点「保存规则」；
- 每条规则支持「应用 / 编辑 / 删除」；
- 规则的新增/编辑/删除直接写回 `label/raw/address_rules.json`；
- 「一键生成全部规则数据」→ 按每条规则的条数一次性生成完整数据集。

### 数据源在线编辑

数据源面板的**数量数字**和步骤数据源旁的**数量数字**均可点击，打开弹窗在线编辑（每行一个值），保存后立即生效并**直接写回 `label/raw/*.txt`**。
